# BashReconGUI
-This Bash script will invoke a functional terminal-based GUI that will ask the user to perform passive recon (WHOIS, DIG, DNSENUM, theHarvester) and active recon (NMAP scans) on a specified target.
-Output of the selected tools will be sent to ./guiActivePassiveRecon_scan_results with time-stamped directories for each scan.
